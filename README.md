# 8051 Smart Digital Clock System 

## Project Overview

The 8051 Smart Digital Clock System is an embedded project developed using the AT89C51 microcontroller. It is designed to display real-time clock information on a 16x2 LCD and includes additional features such as alarm notification and stopwatch mode. The system is controlled using three push buttons for easy operation. This project demonstrates practical knowledge of timer programming, LCD interfacing, and multi-function embedded system design.
 
## Key Features

- Real-time digital clock display (Hours : Minutes : Seconds)
- Alarm setting with buzzer indication
- Stopwatch mode for elapsed time measurement
- Multi-mode operation using three push buttons
- User-friendly LCD interface
- Accurate timer-based system logic

## Working Principle

The system is controlled by the AT89C51 (8051) microcontroller. It uses the internal timer to count time in one-second intervals. Based on this, the system updates hours, minutes, and seconds continuously.
The current time is shown on the 16x2 LCD display. The LCD is also used to show different modes such as clock mode, alarm setting mode, and stopwatch mode.
Three push buttons are used to control the system. These buttons help the user change modes, set the time, set the alarm, and operate the stopwatch.
When the set alarm time becomes equal to the current clock time, the buzzer turns ON and gives an alert sound.
The stopwatch mode is used to measure elapsed time. It counts seconds, minutes, and hours when started by the user.
This project shows the use of timer programming, LCD interfacing, button control, and multiple functions using the 8051 microcontroller.
